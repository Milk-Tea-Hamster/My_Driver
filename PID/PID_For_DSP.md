# PID 在 MCU 信号处理中的应用场景

## 1. PID 的信号处理本质

从信号处理角度看，PID 控制器本质上是一个**可配置的 IIR 滤波器**——对误差信号同时做放大、累积平滑、变化率前馈，然后合成输出。

| PID 项 | 信号处理等效 | 作用 |
|--------|-------------|------|
| P（比例） | 线性放大器 | 误差即时增益，决定响应速度 |
| I（积分） | 累积平均器/自适应偏置补偿 | 消除 DC offset 和稳态误差 |
| D（微分） | 变化率检测器/相位超前滤波器 | 预测趋势，抑制过冲 |

## 2. 典型 MCU 信号处理场景

### 2.1 传感器信号稳定化

PID 最直接的作用就是让传感器读数稳定在目标值附近。

**实例：恒温控制**
- 输入信号：NTC 热敏电阻 → ADC 采样 → 转换为温度值（可能需要经过低通滤波预处理）
- 目标信号：37.0°C（设定点）
- PID 输出：PWM 占空比 → 驱动加热元件
- D 项补偿热惯性延迟（热传导有 τ 时间常数）
- I 项消除环境散热导致的稳态误差

**实例：恒流 LED 驱动**
- 输入信号：采样电阻电压 → ADC → 电流值
- 目标信号：恒定 350mA
- PID 输出：DC-DC 转换器占空比

### 2.2 电机伺服控制

**速度控制**
- 输入信号：编码器脉冲 → 频率测量 → 转速（RPM）
- PID 输出：PWM → H 桥 → 电机电压
- 信号处理链：脉冲整形 → 频率计数 → 低通滤波 → PID → PWM 调制

**位置控制**
- 输入信号：编码器计数 → 角度/位移
- 目标信号：目标位置
- 需要注意积分饱和（用 clamped 或 conditional 模式）

### 2.3 信号调理与补偿

**传感器动态补偿**
- 某些传感器（电化学、湿度）响应慢，呈一阶惯性特性
- D 项做相位超前补偿，加快等效响应速度
- P 项设得较小，让 I 项主导消除稳态偏差

**基线漂移校正**
- 长时间测量中传感器基线会漂移（如 ECG 电极极化）
- 用极慢的 I 项跟踪低频漂移并补偿
- 这本质上是 PID 在做一个**高通滤波**（输出 = 原始信号 - I 项累积的漂移估计值）

### 2.4 电源管理

**恒压/恒流充电**
- 输入信号：ADC 采样输出电压/电流
- 目标信号：设定的电压/电流曲线
- PID 输出：DC-DC 占空比
- 信号处理要点：ADC 采样需做去噪（中值滤波或移动平均），否则 D 项会放大噪声

**MPPT 太阳能最大功率跟踪**
- 扰动观察法的核心是 P 控制器 + 自适应步长
- 本质上是个极值搜索控制问题
- PID 用于稳定工作点，避免在最大功率点附近振荡

### 2.5 信号发生与跟踪

**锁相环（PLL）辅助**
- PID 可以作为 PLL 的环路滤波器
- P 项调整相位误差 → VCO 频率修正
- I 项跟踪频率偏移
- 输出是稳定的频率信号

**任意波形跟踪**
- 目标值随时间变化（如正弦波）
- PID 驱动执行器跟踪这个动态目标
- D 项在这里特别重要——它预测目标变化趋势

## 3. 信号处理链路中的 PID 位置

```
传感器 → [模拟前端] → ADC → [数字滤波] → PID控制器 → [输出映射] → DAC/PWM → 执行器
                                    ↑
                              目标值设定
```

关键设计考量：
- **ADC 前面的模拟滤波**：抗混叠，至少是 RC 低通
- **ADC 后面的数字滤波**：可选，去噪（中值滤波/移动平均）
- **PID 采样率**：通常取系统带宽的 5~10 倍
- **输出映射**：PID 输出是浮点数，需映射到 PWM 占空比/DAC 码值

## 4. 死区的信号处理意义

死区本质上是**非线性量化器**——误差信号在死区范围内被量化为零：

```
if |error| < deadzone → error = 0
```

适用场景：
- ADC 有量化噪声时，防止 PID 在设定点附近高频抖动
- 机械系统有 backlash（回差），用死区避免反复修正
- 注意：死区过大 → 系统永远到不了目标值，会有残余稳态误差

## 5. 积分模式的信号处理视角

| 模式 | 信号处理等效 | 适用场景 |
|------|-------------|---------|
| Standard（标准） | 纯积分器 | 一般场景 |
| Clamped（限幅） | 带饱和限幅的积分器 | 执行器有物理限幅（如 PWM 0~100%） |
| Conditional（条件） | 门控积分器，仅小误差时开启 | 大范围阶跃响应，防止 windup |

conditional 模式等价于：对误差信号做一个**幅度判断**，只有误差落在阈值窗口内才让积分器工作。

## 6. 微分模式的抗噪声考量

D 项对高频噪声极其敏感（微分放大高频分量）。针对信号处理有几种策略：

1. **Derivative on Measurement**：不对 setpoint 突变求导，避免"微分 kick"
2. **前置低通滤波**：在进入 PID 之前对测量信号做低通滤波
3. **采样率不要太高**：采样过快 → delta_m 变小 → 量化噪声占比增大

## 7. 调参的信号处理视角

| 现象 | 频域解释 | 调参方向 |
|------|---------|---------|
| 振荡 | 闭环增益在穿越频率处相位裕度不足 | 降 Kp 或增 D |
| 响应慢 | 闭环带宽太低 | 增大 Kp |
| 稳态误差 | 低频增益不够 | 增大 Ki 或开启积分 |
| 过冲大 | 阻尼不足 | 降 Kp 或增 D |
| 噪声大 | 高频增益太高 | 降 Kd 或加低通滤波 |

可以把 PID 调参看作**在频域中塑形闭环传递函数**：Kp 抬高中频，Ki 抬高低频，Kd 抬高高频。

## 8. 代码骨架（C 语言 + MCU）

```c
#include "pid.h"

#define ADC_BUF_SIZE 8

static PIDController pid;
static float adc_buf[ADC_BUF_SIZE];
static uint8_t adc_idx;

/* 移动平均滤波 */
static float filter_adc(float raw) {
    adc_buf[adc_idx % ADC_BUF_SIZE] = raw;
    adc_idx++;
    float sum = 0.0f;
    for (int i = 0; i < ADC_BUF_SIZE; i++) sum += adc_buf[i];
    return sum / ADC_BUF_SIZE;
}

void control_init(void) {
    PID_Init(&pid, 2.0f, 0.5f, 0.05f);
    PID_SetTarget(&pid, 100.0f);
    PID_SetSampleTime(&pid, 0.01f);
    PID_SetDeadzone(&pid, 0.2f);
    PID_SetIntegralModeWithValue(&pid, PID_INTEGRAL_CLAMPED, 50.0f);
    PID_SetDerivativeMode(&pid, PID_DERIVATIVE_ON_MEASUREMENT);
}

/* 10ms 定时中断 */
void control_timer_callback(void) {
    float raw = adc_read();
    float filtered = filter_adc(raw);     // 前置低通
    float output = PID_Calc(&pid, filtered, 100.0f, 0.0f);
    pwm_set_duty((uint16_t)output);
}
```
