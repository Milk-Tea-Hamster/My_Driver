# PCM5102A 异步时钟模式 I2S 扫频正弦波 — STM32F407VET6 配置指南

## 一、PCM5102A 简介

PCM5102A 是 TI 出品的一款 2.1 VRMS、112dB 立体声音频 DAC，支持 32-bit / 384kHz PCM 输入。其核心优势是**内置 PLL 时钟恢复**——不需要主机提供 MCLK（主时钟），仅需 BCK、LRCK、DIN 三根 I2S 信号线即可工作。这种模式称为"异步时钟模式"或"无 MCLK 模式"。

---

## 二、硬件引脚连接

### 2.1 I2S 通讯引脚（必须）

| PCM5102A 引脚 | 方向 | STM32F407VET6 引脚 | 功能 | AF |
|---|---|---|---|---|
| **SCK (BCK)** | 输入 | **PB10** | I2S 位时钟 | AF5 (I2S2_CK) |
| **LRCK (WS)** | 输入 | **PB12** | I2S 左右声道时钟 (帧同步) | AF5 (I2S2_WS) |
| **DIN** | 输入 | **PC3** | I2S 串行数据 | AF5 (I2S2_SD) |

### 2.2 硬件模式配置引脚（必须）

PCM5102A 默认为**硬件配置模式**（未通过 I2C 编程时）。以下引脚在上电或 XSMT 拉高时被锁存：

| PCM5102A 引脚 | 推荐连接 | 说明 |
|---|---|---|
| **XSMT** | **PA0 (GPIO 输出)** | 软静音控制。`LOW` = 静音，`HIGH` = 正常输出。**必须拉高才能出声** |
| **FMT** | **GND** | 音频格式选择。`LOW` = I2S (Philips 标准)，`HIGH` = Left-Justified |
| **DEMP** | **GND** | 去加重控制。`LOW` = 关闭。数字音频无需去加重 |
| **FLT** | **GND** | 滤波器延迟。`LOW` = 正常延迟（标准 FIR），`HIGH` = 低延迟 |
| **SCL** | **悬空** | I2C 时钟。硬件模式下不接，内部下拉 |
| **VIN** | **3.3V** | 电源 |
| **GND** | **GND** | 地 |

### 2.3 不需要连接的引脚

| 引脚 | 原因 |
|---|---|
| **MCLK** | PCM5102A 无此引脚——内置 PLL 从 BCK 恢复系统时钟 |
| **PC2 (I2S2_ext_SD)** | 全双工模式的扩展数据引脚，PCM5102 只需要单向 TX |

## 三、时钟树分析与计算

### 3.1 系统时钟

```
HSE (25MHz) → /PLLM (25) → VCO输入 1MHz
                            → ×PLLN (336) → VCO 336MHz
                                           → /PLLP (2) → SYSCLK = 168MHz
                                           → /PLLQ (4) → 84MHz (USB/48MHz相关)
```

### 3.2 I2S 时钟（独立于系统时钟的 PLLI2S）

```
HSE (25MHz) → /PLLM (25) → 1MHz → ×PLLI2SN → VCO → /PLLI2SR → I2S_CLK
```

**核心公式：** 当 MCKOE = 0（不输出 MCLK）时，I2S 时钟分频关系为：

```
Fs = I2S_CLK / (32 × (2 × I2SDIV + ODD))
```

其中 `I2SDIV` 为 8 位整数分频值，`ODD` 为奇数分频因子（0 或 1）。I2S Philips 标准下每声道占用 32 个 BCK 周期，故分母为 32。

### 3.3 推荐配置表

#### 方案 A：当前 PLLI2S = 96MHz（PLLI2SN=192, PLLI2SR=2）

| 目标采样率 | 所需 D 值 | I2SDIV | ODD | 实际采样率 | 误差 |
|---|---|---|---|---|---|
| 48 kHz | 62.5 | 31 | 1 | 47,619 Hz | -0.79% |
| 44.1 kHz | 68.03 | 34 | 0 | 44,117.6 Hz | 0.04% |
| 96 kHz | 31.25 | 15 | 1 | 95,238 Hz | -0.79% |

D = I2S_CLK / (32 × Fs)，取 D = 2 × I2SDIV + ODD

**说明：当前 PLLI2S=96MHz 时 48KHz 有 -0.79% 误差（47,619Hz），对扫频测试可接受。如需精确 48KHz，可改 PLLI2SN=258/PLLI2SR=3 获得 86MHz（误差 0.02%）。**

### 4.3 `i2s.c` 修改要点

```c
void MX_I2S2_Init(void)
{
    hi2s2.Instance = SPI2;
    hi2s2.Init.Mode = I2S_MODE_MASTER_TX;
    hi2s2.Init.Standard = I2S_STANDARD_PHILIPS;
    hi2s2.Init.DataFormat = I2S_DATAFORMAT_16B;
    hi2s2.Init.MCLKOutput = I2S_MCLKOUTPUT_DISABLE;
    hi2s2.Init.AudioFreq = I2S_AUDIOFREQ_48K;        // 8K → 48K
    hi2s2.Init.CPOL = I2S_CPOL_LOW;
    hi2s2.Init.ClockSource = I2S_CLOCK_PLL;
    hi2s2.Init.FullDuplexMode = I2S_FULLDUPLEXMODE_DISABLE;  // ENABLE → DISABLE
    HAL_I2S_Init(&hi2s2);
}
```

`HAL_I2S_MspInit()` 中删除 PC2 (I2S2_ext_SD) 的 GPIO 初始化代码块。

### 4.4 `gpio.c` 新增 XSMT 初始化

```c
void MX_GPIO_Init(void)
{
    GPIO_InitTypeDef GPIO_InitStruct = {0};

    // 现有 GPIO 时钟使能...

    // XSMT 控制引脚 (PA0)
    GPIO_InitStruct.Pin = GPIO_PIN_0;
```

## 五、I2S 数据格式说明

PCM5102A 工作在 **I2S Philips 标准 + 16bit 数据** 模式时：

```
BCK:  _/‾\_/‾\_/‾\_/‾\_/‾\_/‾\_/‾\ ...  (64个时钟周期/帧)
LRCK: ‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾\_____________  (高=左声道, 低=右声道)
      左声道(32 BCK)    右声道(32 BCK)
DIN:  [16bit数据+16bit零填充][16bit数据+16bit零填充]
```

- 每帧 64 个 BCK 周期
- 左声道在 LRCK 为高时传输，右声道在 LRCK 为低时传输
- 16bit 数据位于每声道 32bit 时隙的高位（MSB-first），低 16bit 为填充
- STM32 HAL 的 `HAL_I2S_Transmit_DMA()` 发送的 16bit 数组：`[L0, R0, L1, R1, ...]` 交错排列

## 六、扫频正弦波 DMA 发送实现要点

### 6.1 整体架构

```
正弦波表(256点) → DDS相位累加器 → 左右声道填充
    → DMA双缓冲(ping/pong) → HAL_I2S_Transmit_DMA()
    → PB10(BCK) + PB12(LRCK) + PC3(DIN) → PCM5102A
```

### 6.2 关键代码框架

- **DDS 相位累加器**：`phase += phase_increment`，`phase_increment = freq × 2^32 / Fs`
- **双缓冲 DMA**：使用 `HAL_I2S_TxHalfCpltCallback` 和 `HAL_I2S_TxCpltCallback` 分别填充前后半缓冲区
- **扫频**：在回调中按时间改变 `phase_increment`，实现线性或对数扫频
- **缓冲区大小**：建议 `BUFFER_SIZE = 2048`（1024 个立体声采样点 × 2 声道）

### 6.3 启动流程

```c
// 1. 取消静音
HAL_GPIO_WritePin(GPIOA, GPIO_PIN_0, GPIO_PIN_SET);  // XSMT = HIGH

// 2. 填充初始缓冲区
FillBuffer(tx_buffer, BUFFER_SIZE);

// 3. 启动 DMA I2S 发送
HAL_I2S_Transmit_DMA(&hi2s2, (uint16_t*)tx_buffer, BUFFER_SIZE);
```

## 七、常见问题排查

| 现象 | 可能原因 |
|---|---|
| 无输出 | XSMT 未拉高（检查 PA0 = HIGH） |
| 有噪声无音乐 | FMT 接错了（应接 GND 选 I2S 格式） |
| 声音断续/杂音 | BCK 频率不准（检查 PLLI2S 配置的误差率） |
| 声道反了 | LRCK 极性设置或 PCM5102A 的 I2S 标准配置 |
| HAL_I2S_Init 失败 | Full Duplex 模式下 I2S2 和 I2S3 必须同时配置，改为单工即可 |
| 代码卡死 | DMA 中断未开启；检查 NVIC 中 I2S2 中断是否使能 |
