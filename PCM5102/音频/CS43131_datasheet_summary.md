# CS43131 130dB、32 位高性能 DAC，集成耳机驱动与阻抗检测

## 概述

CS43131 是一款高性能、32 位分辨率的立体声音频 DAC，支持最高 384kHz 采样率，并集成低噪声、以地为中心的耳机放大器。该器件采用先进的 32 位过采样多比特调制器，配合失配整形技术，可消除因片上元件失配引起的失真。

## 功能说明

### 模拟输出

模拟输出模块包含独立的伪差分耳机 Class H 放大器输出。片上反相电荷泵产生与输入等值的正负电压，使得自适应满量程输出摆幅以地为中心。由此产生的内部放大器供电电压可为 ±VCP 或 ±VP_LDO（HV_EN = 1 时为 ±3.0V，HV_EN = 0 时为 ±2.6V）。

反相架构消除了对大型直流隔直电容的需求，并使放大器能够在较低供电电压下为耳机负载提供更高的功率。此自适应供电方案将传统 Class AB 放大器转换为更高能效的 Class H 放大器。

### Class H 放大器输出

CS43131 耳机输出放大器采用 Cirrus Logic 双模式 Class H 技术。该技术在保持高性能的同时，最大限度地提高了传统 Class AB 放大器的工作效率。在 Class H 放大器设计中，提供给放大器的供电轨电压随正在放大的音乐段落的需求而变化。这避免了在节目素材的低功率段落或以低音量播放时不必要的能量浪费。

内部电荷泵是 CS43131 中实现的双模式 Class H 技术的核心组件，它负责为耳机放大器产生供电轨电压。电荷泵从 VCP 或 VP 引脚上的电压获取输入，并由此产生提供给放大器输出级的差分供电轨电压。

HV_EN 设置决定 VP_LDO 电压：
- HV_EN = 0：VP_LDO 电压为 2.6V
- HV_EN = 1：VP_LDO 电压为 3.0V

HV_EN = 1 设置是支持 600Ω 及以上负载达到 1.7V 满量程电压所必需的。在该设置下，VP 最低需高于 3.3V，且不支持低于 600Ω 的任何负载。当 HV_EN = 0 时，最大输出电压为 1.4V RMS 满量程电压。

### 供电控制选项

该器件支持两种运行模式：标准 Class AB 和自适应输出信号。提供给放大器输出级的供电轨电压组取决于 ADPT_PWR 设置：

- **标准 Class AB 运行（ADPT_PWR = 001 或 010）**：提供给放大器的供电轨电压分别保持为 ±VP_LDO 或 ±VCP。无论输出信号电平如何，提供给输出级的供电轨电压均保持恒定。

- **自适应输出信号（ADPT_PWR = 111）**：发送给放大器的供电轨电压仅基于信号是否会导致放大器在较低供电轨电压组的特定阈值处发生削波。

### 宽带平坦模式

CS43131 专门针对宽带平坦回放进行了优化，通过 PCM_WBF_EN 位使能。此模式仅应在 PCM 以 192kHz 播放时启用。在其他速度或模式下运行时，应正确禁用该位。

### DSD 接口

CS43131 具有专用 DSD 接口，支持最高 256•Fs 的 DSD 流。DSD 接口与 XSP 共享引脚。DSD 处理器采用免抽取式 DSD 处理技术，可实现匹配的 PCM 电平输出、DSD 音量控制以及 50kHz 片上滤波器等功能。

### 音频串行端口（ASP）

ASP 支持 PCM 和 DoP 流播放。可配置为支持常用音频接口，包括 TDM/I2S 和左对齐（LJ）。串行端口可作为时序主设备运行，也可作为另一设备时序的从设备运行。

### 滤波器选项

对于 PCM/TDM 模式，可选择以下插值滤波器选项：
- 快速滚降和慢速滚降插值滤波器选项
- 在上述各选项中，均可使用低延迟和普通相位补偿滤波选项
- 提供非过采样（NOS）模式，可最大限度减少内部数字处理

### 耳机检测

CS43131 提供耳机存在检测和负载检测功能。可通过 HP_DETECT 检测引脚检测插头的存在与否。存在检测功能通过在 CS43131 内部设置一个小电流源来实现，当引脚悬空（无插头）时将其上拉。

### 耳机阻抗测量

CS43131 可测量耳机直流负载在 20Hz 至 20kHz 范围内的阻抗。测量过程包括向耳机负载施加缓慢上升的电压并测量由此产生的电阻。

## 应用说明

### 上电时序

上电时序：
- VP 必须最先上电
- 在 RESET 释放之前，其他所有电源可以任意顺序上电

下电时序：
- RESET 置位后，VA/VCP/VL/VD 可以任意顺序移除
- VP 必须最后下电

### 晶振选型

CS43131 使用外部晶振作为内部 MCLK 的时钟源。支持的晶振包括：
- River Electronics FCX-06-22.5792J51933（22.5792MHz）
- River Electronics FCX-06-24.5760J51930（24.576MHz）
- NDK NX2016SA 22.5792M EXS00A-CS09116（22.5792MHz）
- TXC 8Y22570001（22.5792MHz）

## 总结

CS43131 是一款高性能立体声音频 DAC，将出色的音频性能与集成耳机放大器相结合，非常适合便携式音频应用。其先进特性包括 32 位分辨率、最高 384kHz 采样率支持、集成 DSD 处理、耳机检测与阻抗测量，以及可提高效率的 Class H 放大器技术。该器件提供卓越的动态范围（130dB A 加权）和低失真（–115dB THD+N），适用于高端音频应用场景。
