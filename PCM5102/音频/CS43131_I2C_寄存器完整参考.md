# CS43131 I2C 配置寄存器完整参考

> 来源: CS43131 数据手册 (C1554754) Section 6/7 — Register Quick Reference & Register Descriptions
> I2C 地址: 7-bit = 0x60 (ADR 引脚决定高位)，实际地址由 ADR 引脚电平决定

---

## 一、I2C 通信协议

### 1.1 物理层

| 参数 | 规格 |
|------|------|
| I2C 速率 | 最高 1 MHz (Fast-mode Plus) |
| I2C 地址 | 7-bit，由 ADR 引脚决定 |
| 寄存器地址空间 | 24-bit (3 字节地址) |
| 数据宽度 | 每寄存器 1 字节 (8-bit) |
| 控制端口操作 | Section 4.12 (I2C Control Port) |

### 1.2 写操作时序 (5 字节)

```
START + SLAVE_ADDR(W) + ACK + ADDR[23:16] + ACK + ADDR[15:8] + ACK + ADDR[7:0] + ACK + 0x01(CMD) + ACK + DATA[7:0] + ACK + STOP
```

重点说明:
- 最后一字节地址后发 **0x01** 表示寄存器访问命令 (CMD byte)
- 写: 发完 CMD 0x01 后再发 1 字节数据
- 对于多字节寄存器 (PLL_FRAC 等)，需按地址递增逐个写入

### 1.3 读操作时序 (RESTART 方式)

```
START + SLAVE_ADDR(W) + ACK + ADDR[23:16] + ACK + ADDR[15:8] + ACK + ADDR[7:0] + ACK + 0x01(CMD) + ACK + RESTART + SLAVE_ADDR(R) + ACK + DATA[7:0] + NACK + STOP
```

### 1.4 I2C 地址

- ADR 引脚决定 7-bit 地址，常见值为 **0x60** (ADR 接 GND 时)
- 具体对应关系参考数据手册 I2C 控制端口章节

### 1.5 HPIN 低功耗模式限制

当 `HP_IN_LP = 1` 时，I2C 最高速率限制为 **400 kHz**。

## 三、全局寄存器 (0x01xxxx)

### 3.1 器件 ID (只读)

| 地址 | 名称 | Bits | 默认值 | 描述 |
|------|------|------|--------|------|
| `0x010000` | DEVID_A/B | [7:4]=DEVIDA, [3:0]=DEVIDB | `0x43` | 器件型号首两位: "4", "3" |
| `0x010001` | DEVID_C/D | [7:4]=DEVIDC, [3:0]=DEVIDD | `0x13` | 器件型号三四位: "1", "3" |
| `0x010002` | DEVID_E | [7:4]=DEVIDE, [3:0]=Reserved | `0x10` | 器件型号第五位: "1" |

> 完整型号 ID = "43131"

### 3.2 版本/子版本 ID (只读)

| 地址 | 名称 | Bits | 描述 |
|------|------|------|------|
| `0x010004` | REVID | [7:4]=AREVID (Alpha版本), [3:0]=MTLREVID (Metal版本) | e.g. A0, B2 |
| `0x010005` | SUBREVID | [7:0]=SUBREVID | 子版本级别。Bit7=0, Bits[6:0]=xxx |

### 3.3 系统时钟控制 — `0x010006` (R/W)

> **最关键的寄存器之一**，控制 MCLK 源选择和频率声明。

| Bits | 名称 | 默认 | 描述 |
|------|------|------|------|
| [7:3] | — | 0 | Reserved |
| [2] | **MCLK_INT** | 1 | MCLK_INT 频率声明: **0**=24.576 MHz, **1**(默认)=22.5792 MHz |
| [1:0] | **MCLK_SRC_SEL** | 10 | MCLK 源选择: **00**=XTAL/MCLK 直通, **01**=PLL 输出, **10**(默认)=RCO, **11**=Reserved |

**MCLK_SRC_SEL 切换注意事项:**
- 切换后需等待 **≥150 μs** 稳定
- 推荐的切换流程: 先切到 RCO (0x06) → 等待150μs → 再切到目标源
- MCLK_SRC_SEL=00 (XTAL 直通): MCLK_INT 必须正确声明晶振频率 (24.576/22.5792 MHz)
- MCLK_SRC_SEL=01 (PLL 输出): 使用前必须上电 PLL 并等 PLL_READY_INT 置位

### 3.4 串口采样率 — `0x01000B` (R/W)

| Bits | 名称 | 默认 | 描述 |
|------|------|------|------|
| [7:4] | — | 0 | Reserved |
| [3:0] | **ASP_SPRATE** | `0001` | ASP 采样率 (Master/Slave 模式均需编程) |

编码:

| 值 | 采样率 | 值 | 采样率 |
|----|--------|----|--------|
| `0000` | 32 kHz | `0101` | 176.4 kHz |
| `0001` | **44.1 kHz** (默认) | `0110` | 192 kHz |
| `0010` | 48 kHz | `0111` | 352.8 kHz |
| `0011` | 88.2 kHz | `1000` | 384 kHz |
| `0100` | 96 kHz | `1001`–`1111` | Reserved |

> 若 ASP_SPRATE=384kHz 且 CS43131 为 Master Mode，MCLK_INT 必须为 24.576 MHz

### 3.5 串口采样位深 — `0x01000C` (R/W)

| Bits | 名称 | 默认 | 描述 |
|------|------|------|------|
| [7:4] | — | 0 | Reserved |
| [3:2] | **XSP_SPSIZE** | `01` | XSP 位深: `00`=32bit, `01`=24bit (默认), `10-11`=Reserved |
| [1:0] | **ASP_SPSIZE** | `01` | ASP 位深: `00`=32bit, `01`=24bit (默认), `10`=16bit, `11`=8bit |

### 3.6 Pad 接口配置 — `0x01000D` (R/W)

| Bits | 名称 | 默认 | 描述 |
|------|------|------|------|
| [7:2] | — | 0 | Reserved |
| [1] | **XSP_3ST** | 1 | XSP 时钟驱动在 Master 模式下的状态: 0=Hi-Z, **1**=Active (默认) |
| [0] | **ASP_3ST** | 1 | ASP 时钟驱动在 Master 模式下的状态: 0=Hi-Z, **1**=Active (默认) |

> 设置 xSP_3ST 之前必须先关断对应串口 (PDN_xSP=1)，清零后才能上电。

## 四、电源控制 (0x02xxxx)

### 4.1 掉电控制 — `0x020000` (R/W)

> **最重要的电源控制寄存器**，控制各功能域的上下电。PDN=1 表示掉电，PDN=0 表示上电。

| Bit | 名称 | 默认 | 描述 |
|-----|------|------|------|
| 7 | **PDN_XSP** | 1 | XSP (DSD 串口) 掉电 |
| 6 | **PDN_ASP** | 1 | ASP (I2S 串口) 掉电 |
| 5 | **PDN_DSDIF** | 1 | DSD 接口掉电 |
| 4 | **PDN_HP** | 1 | 耳机放大器 + DAC 掉电。置位时音频输出软斜坡到静音 |
| 3 | **PDN_XTAL** | 1 | 晶振驱动掉电 |
| 2 | **PDN_PLL** | 1 | PLL 模块掉电 |
| 1 | **PDN_CLKOUT** | 1 | CLKOUT 输出掉电 (输出驱动为低电平) |
| 0 | — | 0 | Reserved |

**初始化上电典型序列:**
1. `PDN_XTAL=0` → 等待 XTAL_READY_INT
2. `PDN_PLL=0` (如需 PLL) → 配置 PLL → PLL_START=1 → 等待 PLL_READY_INT
3. 切换 MCLK 源到 XTAL/PLL
4. `PDN_ASP=0` (I2S 上电)
5. `PDN_HP=0` (耳机放大器上电) → 等待 PDN_DONE_INT

### 4.2 晶振驱动电流 — `0x020052` (R/W)

| Bits | 名称 | 默认 | 描述 |
|------|------|------|------|
| [7:3] | — | 0 | Reserved |
| [2:0] | **XTAL_IBIAS** | `100` | 晶振偏置电流强度: `010`=15.0μA, **100**=12.5μA (默认), `110`=7.5μA, 其他=Reserved |

> 具体值需对照数据手册 Table 5-1 (Crystal Tuning) 根据实际晶振型号选择。

## 五、PLL 寄存器 (0x03xxxx)

### 5.1 PLL 信息总览

PLL 公式 (数据手册 Eq. 4-1):

```
PLL_OUT = PLL_REF × (PLL_DIV_INT + PLL_DIV_FRAC/2²⁴) / (PLL_REF_PREDIV × PLL_OUT_DIV)
```

其中:
- `PLL_REF` = XTI/MCLK 引脚输入频率
- `PLL_DIV_FRAC` = 24-bit 小数 (0x030002~0x030004)
- `PLL_DIV_INT` = 8-bit 整数 (0x030005)
- `PLL_REF_PREDIV` = 参考预分频 (1/2/4/8) (0x040002)
- `PLL_OUT_DIV` = 输出分频 (0x030008)

### 5.2 PLL 启动 — `0x030001` (R/W)

| Bits | 名称 | 默认 | 描述 |
|------|------|------|------|
| [7:1] | — | 0 | Reserved |
| [0] | **PLL_START** | 0 | PLL 启动位: 0=未启动 (默认), 1=启动。配置完所有分频后置位 |

### 5.3 PLL 小数分频 (24-bit, LE)

| 地址 | 名称 | Bits | 描述 |
|------|------|------|------|
| `0x030002` | PLL_DIV_FRAC_0 | [7:0] = LSB | 小数分频 bits[7:0]，权重 2⁻¹⁷~2⁻²⁴ |
| `0x030003` | PLL_DIV_FRAC_1 | [7:0] = Middle | 小数分频 bits[15:8]，权重 2⁻⁹~2⁻¹⁶ |
| `0x030004` | PLL_DIV_FRAC_2 | [7:0] = MSB | 小数分频 bits[23:16]，权重 2⁻¹~2⁻⁸ |

> 默认值: 全部 `0x00`

### 5.4 PLL 整数分频 — `0x030005` (R/W)

| Bits | 名称 | 默认 | 描述 |
|------|------|------|------|
| [7:0] | **PLL_DIV_INT** | `0x40` (64) | PLL 反馈分频器整数部分 |

### 5.5 PLL 输出分频 — `0x030008` (R/W)

| Bits | 名称 | 默认 | 描述 |
|------|------|------|------|
| [7:0] | **PLL_OUT_DIV** | `0x10` (16) | PLL 最终时钟输出分频值 |

### 5.6 PLL 校准比率 — `0x03000A` (R/W)

| Bits | 名称 | 默认 | 描述 |
|------|------|------|------|
| [7:0] | **PLL_CAL_RATIO** | `0x80` (128) | PLL VCO 校准目标值。详见 Section 4.7.2 |

> 数据手册推荐值: **139 (0x8B)**

### 5.7 PLL 模式 — `0x03001B` (R/W)

| Bits | 名称 | 默认 | 描述 |
|------|------|------|------|
| [7:2] | — | 0 | Reserved |
| [1] | **PLL_MODE** | 1 | 500/512 因子: 0=bypass, **1**=不bypass (默认) |
| [0] | — | 1 | Reserved |

> 当前驱动使用的 PLL_MODE=1 (高速模式)

### 5.8 PLL 参考预分频 — `0x040002` (R/W)

| Bits | 名称 | 默认 | 描述 |
|------|------|------|------|
| [7:2] | — | 0 | Reserved |
| [1:0] | **PLL_REF_PREDIV** | `01` | `00`=÷1, **01**=÷2 (默认), `10`=÷4, `11`=÷8 |

### 5.9 PLL 典型配置流程

```
1. PDN_PLL=0 (上电 PLL 域)
2. 写 PLL_DIV_FRAC_0/1/2 (24-bit 小数)
3. 写 PLL_DIV_INT
4. 写 PLL_REF_PREDIV (0x040002)
5. 写 PLL_OUT_DIV (0x030008)
6. 写 PLL_CAL_RATIO = 0x8B
7. 写 PLL_MODE = 0x01 (或 0x03 保留默认)
8. PLL_START = 1
9. 等待 PLL_READY_INT (~620-1000μs，推荐 2ms)
10. MCLK_SRC_SEL 切到 01 (PLL 输出)
```

## 六、ASP 和 XSP 寄存器 (0x04xxxx)

### 6.1 CLKOUT 控制 — `0x040004` (R/W)

| Bits | 名称 | 默认 | 描述 |
|------|------|------|------|
| [7:5] | — | 0 | Reserved |
| [4:2] | **CLKOUT_DIV** | `000` | 内部 MCLK→CLKOUT 分频: `000`=÷2 (默认), `001`=÷3, `010`=÷4, `011`=÷8 |
| [1:0] | **CLKOUT_SEL** | `00` | CLKOUT 源选择: `00`=XTAL/MCLK (默认), `01`=PLL, `10-11`=Reserved |

### 6.2 ASP 时钟分频器 (Master 模式)

ASP Master 模式下的 SCLK 频率由分数分频器决定:

```
SCLK = MCLK × ASP_N / ASP_M
```

| 地址 | 名称 | 默认 | 描述 |
|------|------|------|------|
| `0x040010` | ASP_N_LSB | `0x01` | ASP 分子 LSB (串口上电时不可更改) |
| `0x040011` | ASP_N_MSB | `0x00` | ASP 分子 MSB。默认 ASP_N=1 |
| `0x040012` | ASP_M_LSB | `0x08` | ASP 分母 LSB (串口上电时不可更改) |
| `0x040013` | ASP_M_MSB | `0x00` | ASP 分母 MSB。默认 ASP_M=8 |

### 6.3 ASP LRCK 时序 (Master 模式)

| 地址 | 名称 | 默认 | 描述 |
|------|------|------|------|
| `0x040014` | ASP_LCHI_LSB | `0x1F` | LRCK 高电平持续时间 LSB (单位: SCLK 周期) |
| `0x040015` | ASP_LCHI_MSB | `0x00` | LRCK 高电平持续时间 MSB。默认 ASP_LCHI=31 |
| `0x040016` | ASP_LCPR_LSB | `0x3F` | LRCK 周期 LSB (单位: SCLK 周期) |
| `0x040017` | ASP_LCPR_MSB | `0x00` | LRCK 周期 MSB。默认 ASP_LCPR=63 |

> LCHI < LCPR，串口上电时不可更改

### 6.5 ASP 帧配置 — `0x040019` (R/W)

## 八、DSD 寄存器 (0x06xxxx / 0x07xxxx)

### 8.1 XSP/DSD 通道寄存器 (0x06xxxx)

结构与 ASP 通道寄存器 (0x05xxxx) 完全相同，对应 XSP 串口通道。XSP 通道 2 默认 CH2_EN=1。

### 8.2 DSD 音量控制 (0x07xxxx)

| 地址 | 名称 | 默认 | 描述 |
|------|------|------|------|
| `0x070000` | DSD_VOLUME_B | `0x78` (–60 dB) | DSD 通道 B 音量，0.5dB步进。0x00=0dB, 0x78=-60dB (默认), 0xFF=MUTE |
| `0x070001` | DSD_VOLUME_A | `0x78` (–60 dB) | DSD 通道 A 音量 |

### 8.3 DSD 处理器通路信号控制 1 — `0x070002` (R/W)

| Bit | 名称 | 默认 | 描述 |
|-----|------|------|------|
| 7 | **DSD_RAMP_UP** | 1 | 错误恢复后软音量渐变: 0=立即解除静音, **1**=由DSD_SZC控制 (默认) |
| 6 | **DSD_VOL_BEQA** | 0 | 音量联动: **0**=独立控制 (默认), 1=B跟随A |
| 5 | **DSD_SZC** | 1 | 软斜坡: 0=立即, **1**=软斜坡 (默认) |
| 4 | — | 0 | Reserved |
| 3 | **DSD_AMUTE** | 1 | 自动静音: 0=禁用, **1**=检测到256个重复8-bit静音模式后静音 (默认) |
| 2 | **DSD_AMUTE_BEQA** | 0 | AMUTE联动: **0**=独立 (默认), 1=两通道AMUTE条件均满足才静音 |

```
REG_POP_FREE (0x010010) = 0x00     // 清除 pop-free
REG_HP_POP_FREE (0x080032) = 0x00
PCM_MUTE_A/B = 0  // 解除静音
```

### 15.4 采样率切换序列

```
1. PCM_MUTE_A/B = 1    (静音)
2. PCM_RAMP_DOWN = 1    (软斜坡)
3. PDN_ASP = 1          (关断 I2S 串口)
4. ASP_SPRATE = new_rate
5. ASP_SPSIZE = new_bits
6. 重新配置 I2S 相关寄存器 (通道位宽等)
7. PDN_ASP = 0          (上电 I2S 串口)
8. PCM_MUTE_A/B = 0    (解除静音)
```

## 附录: 关键注意事项

1. **Reserved 位保护**: 所有 Reserved 位必须维持默认值。写寄存器时需要用 读-修改-写 方式保留 Reserved 位。

2. **串口上电锁定**: ASP_N/M/LCHI/LCPR 等分频寄存器在对应串口上电 (PDN_xSP=0) 时不可更改。

3. **MCLK 切换**: 切换 MCLK_SRC_SEL 后必须等待 ≥150μs。推荐通过 RCO 中转。

4. **PDN_HP 更新锁定**: OUT_FS、PCM_WBF_EN 等寄存器位仅在 PDN_HP=1 时可更改。

5. **HP_IN_LP 限制**: HPIN 低功耗模式下 I2C 最高 400kHz。

6. **Pop-Free**: 每次 PDN_HP 清除 (上电耳机) 都需执行 pop-free 序列。

7. **PLL 分频器小数部分为 24-bit LE**: 0x030002=[7:0], 0x030003=[15:8], 0x030004=[23:16]。
